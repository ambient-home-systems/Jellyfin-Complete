# Logo

The split-flap M, concept A of five (chosen 4 Nov). It's a yellow departure-board tile, as in the app's "Timetable" design, carrying the M of Maverick.

| File | Use |
|---|---|
| [mark.svg](mark.svg) | The mark on light backgrounds |
| [mark-dark.svg](mark-dark.svg) | On dark backgrounds: the tile's hinge pins turn light |
| [../../public/favicon.svg](../../public/favicon.svg) | Browser tab icon: no pins, a bigger M, for 16–32 px |

- **Colours:** Timetable yellow `#ffd200` and ink `#131313`, from [DESIGN.md](../../DESIGN.md).
- **Wordmark:** "Maverick" in Archivo, weight 800, width 70, with "Jellyfin Complete" beneath in small capitals. The app sets it in live text, never as an image.
