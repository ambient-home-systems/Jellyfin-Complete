# Archivo

Archivo variable font (latin subset, `wdth` 62–125 and `wght` 100–900), from Google Fonts on 2026-11-02 (`fonts.gstatic.com/s/archivo/v25/k3kQo8UDI-1M0wlSfdnoLg.woff2`). It is self-hosted because the app runs on a LAN.
