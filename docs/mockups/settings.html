Settings: design notes

One long page with a section index, because a weekly session usually changes one thing. Every control is a standard form element.

  1. 1

    Connections

    Each service gets one row: URL, masked key with Replace (never Reveal), and live status. The status shows each state it can be in: OK with version, rate-limited, testing (with a spinner), and an error that names the cause (401, key rejected) and turns the field red. MDBList states that its key is optional.

  2. 2

    Modes and guardrails

    Dry run comes first, because it overrides everything below it. The defaults table shows which collections override each action, so you can see where an override hides.

    Guardrails are plain inputs. The two that must never be off (already present, exclusion list) are checked and locked, which shows they exist without letting you turn them off.

  3. 3

    IMDb route

    The four routes from the brief as radio cards, each with a one-line trade-off. The recommendation cites the 2 Nov spike result. Hash health sits in the heading line. A PERSISTED_QUERY_NOT_FOUND error turns it red and raises a Dashboard notice.

  4. 4

    Radarr and Sonarr defaults

    Two columns with the same fields the Missing panel uses, every list read live from each app. Collections can override them, for example a kids' collection with its own root folder.

  5. 5

    Schedules beside the neighbours

    A 24-hour strip draws each job as a tick at its start time, with no duration implied. It puts this app's jobs (solid) next to Jellyfin-Auto-Collections at 04:00 and Kometa at 05:00 (dashed), so collisions are visible before you edit a time. Only the next job is on yellow. Cron is shown but secondary, and every job lists its next run.

  6. 6

    Presets

    All 19 Kometa seasonal presets (plus the show franchise and universe packs), each with an on/off switch, its window, its sources and how many films you own (real counts from the 2 Nov server spike). The last column records every place you've changed something from Kometa's version, so parity drift is never hidden.
